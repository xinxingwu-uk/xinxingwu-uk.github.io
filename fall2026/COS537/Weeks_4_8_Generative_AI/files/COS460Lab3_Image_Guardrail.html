Short Image Guardrail Example¶

Big idea¶

For text, we used:

User → Guardrail → Language Model

For images, we can use the same idea:

Image → Guardrail → Vision Model

Our simple guardrail checks:

  1. Is the file a JPG or PNG?
  2. Is the file smaller than 5 MB?
  3. Is the image at least 100 × 100 pixels?

If the image passes, we send it to a small image-captioning model.

Step 2 — Build a very simple image guardrail¶

In [2]:
import os

def image_guardrail(filename, image):
    allowed_types = [".jpg", ".jpeg", ".png"]

    extension = os.path.splitext(filename)[1].lower()

    if extension not in allowed_types:
        return False, "Unsupported file type"

    file_size = os.path.getsize(filename)

    if file_size > 5 * 1024 * 1024:
        return False, "File is larger than 5 MB"

    width, height = image.size

    if width < 100 or height < 100:
        return False, "Image is too small"

    return True, "Image passed the guardrail"


allowed, reason = image_guardrail(filename, image)

print("Allowed:", allowed)
print("Reason :", reason)

Step 4 — Compare WITHOUT vs. WITH the guardrail¶

In [5]:
def caption_image(image):
    inputs = processor(images=image, return_tensors="pt")

    output = model.generate(
        **inputs,
        max_new_tokens=30
    )

    return processor.decode(
        output[0],
        skip_special_tokens=True
    )


print("WITHOUT GUARDRAIL:")
print(caption_image(image))

print()

print("WITH GUARDRAIL:")

allowed, reason = image_guardrail(filename, image)

if allowed:
    print(caption_image(image))
else:
    print("BLOCKED:", reason)

What did we learn?¶

The vision model itself does not have to perform every safety or quality check.

An external image guardrail can check the image before the model receives it.

Part I. True/False Questions

Decide whether each statement is true or false.

1

A proposition is a statement that is either true or false.

View answer
Answer: True. The slides define a proposition as a statement with a truth value of true or false.
2

The symbol p → q represents a biconditional statement.

View answer
Answer: False. p → q is an implication. A biconditional is written p ↔ q.
3

A function maps every element of its domain to exactly one element of its codomain.

View answer
Answer: True. This “exactly one output” requirement is part of the definition of a function.
4

Function composition is usually commutative, so g(f(x)) = f(g(x)) for all functions.

View answer
Answer: False. The slides emphasize that order matters in composition. In the example, g(f(3)) = 49, while f(g(3)) = 19.
5

Linear search requires the input list to be sorted.

View answer
Answer: False. Linear search works even when the data is not sorted.
6

Binary search repeatedly halves a sorted search space and has time complexity O(log n).

View answer
Answer: True. Each comparison eliminates approximately half of the remaining sorted list.
7

A modular inverse of a modulo m exists when gcd(a,m)=1.

View answer
Answer: True. Relatively prime values satisfy the condition required for a modular inverse.
8

Using a Caesar shift of 3, the plaintext HELLO becomes KHOOR.

View answer
Answer: True. Each letter is moved three positions forward: H→K, E→H, L→O, L→O, and O→R.
9

A proof by mathematical induction can omit the base case as long as the inductive step is correct.

View answer
Answer: False. Induction requires a base case and an inductive step. Without the base case, the argument never establishes a starting point.
10

A recursive algorithm that does not move toward a base case may never terminate.

View answer
Answer: True. A sound recursive solution must make progress toward a stopping condition.

Part II. Single-Answer Multiple-Choice Questions

Choose the one best answer for each question.

1

Which logical connective means “and”?

  • A. ¬
  • B. ∧
  • C. ∨
  • D. →
View answer
Answer: B. The conjunction symbol ∧ is pronounced “and.”
2

If A is the set of students in AI and B is the set of students in Discrete Math, what does A ∩ B represent?

  • A. Students taking neither course
  • B. Students taking at least one of the courses
  • C. Students taking both courses
  • D. Students taking AI but not Discrete Math
View answer
Answer: C. Intersection contains the elements shared by both sets.
3

Let f(x)=2x+1 and g(x)=x². What is g(f(3))?

  • A. 19
  • B. 36
  • C. 49
  • D. 81
View answer
Answer: C. First, f(3)=7. Then g(7)=7²=49.
4

What is the worst-case time complexity of linear search?

  • A. O(1)
  • B. O(log n)
  • C. O(n)
  • D. O(n²)
View answer
Answer: C. In the worst case, linear search checks every element.
5

What is gcd(84,30)?

  • A. 2
  • B. 3
  • C. 6
  • D. 12
View answer
Answer: C. The Euclidean algorithm gives remainders 24, 6, and 0; the last nonzero remainder is 6.
6

What is the multiplicative inverse of 3 modulo 7?

  • A. 2
  • B. 3
  • C. 5
  • D. 6
View answer
Answer: C. Since 3 × 5 = 15 ≡ 1 (mod 7), the inverse is 5.
7

In cryptography, what is readable information called before encryption?

  • A. Ciphertext
  • B. Plaintext
  • C. Checksum
  • D. Modulus
View answer
Answer: B. Encryption transforms readable plaintext into ciphertext.
8

In the slides’ tiny RSA-style example, φ(n)=40 and e=3. Which value of d satisfies 3d ≡ 1 (mod 40)?

  • A. 7
  • B. 13
  • C. 21
  • D. 27
View answer
Answer: D. 3 × 27 = 81 ≡ 1 (mod 40).
9

Which induction method assumes several earlier statements, such as P(a), P(a+1), …, P(k), to prove P(k+1)?

  • A. Direct proof
  • B. Proof by contradiction
  • C. Strong induction
  • D. Modus tollens
View answer
Answer: C. Strong induction may use all established earlier cases.
10

A recursive binary search has recurrence T(n)=T(n/2)+1. What running time does this describe?

  • A. O(1)
  • B. O(log n)
  • C. O(n)
  • D. O(2ⁿ)
View answer
Answer: B. Repeatedly dividing the problem size by 2 produces approximately log₂ n recursive levels.

Part III. Multiple-Answer Questions

Select all answers that apply. Each question has two or more correct choices.

1

Which symbols are logical connectives presented in the slides? Select all that apply.

  • A. ¬
  • B. ∧
  • C. ∨
  • D. →
  • E. ↔
  • F. ∈
View answer
Answers: A, B, C, D, and E. They represent negation, conjunction, disjunction, implication, and biconditional. The symbol ∈ means “is an element of.”
2

Which proof strategies are discussed in the Logic and Proofs slides? Select all that apply.

  • A. Direct proof
  • B. Proof by contraposition
  • C. Proof by contradiction
  • D. Checking one example and declaring a general proof
  • E. Modus ponens as a rule of inference
View answer
Answers: A, B, C, and E. One example alone does not prove a general claim.
3

Which interpretations of set operations are correct? Select all that apply.

  • A. A ∩ B contains elements in both A and B.
  • B. A ∪ B contains elements in at least one of the two sets.
  • C. A − B contains elements in A but not in B.
  • D. A ∩ B always contains every element in the universal set.
  • E. Set intersection can model an SQL “AND” condition.
View answer
Answers: A, B, C, and E. Intersection identifies shared members; it does not automatically contain the entire universal set.
4

According to the slides, matrices can be used to represent which items? Select all that apply.

  • A. Relations and networks
  • B. Image pixels
  • C. Transformations such as scaling and rotation
  • D. A 0–1 student-course enrollment relationship
  • E. A guarantee that every represented relation is a one-to-one function
View answer
Answers: A, B, C, and D. A matrix can represent many structures, but it does not by itself guarantee that the relationship is a one-to-one function.
5

Which growth rates grow more slowly than n² for sufficiently large n? Select all that apply.

  • A. log n
  • B. n
  • C. n log n
  • D. 2ⁿ
  • E. n³
View answer
Answers: A, B, and C. Logarithmic, linear, and linearithmic growth are asymptotically slower than quadratic growth.
6

Which applications of modular arithmetic or remainders are identified in the Number Theory slides? Select all that apply.

  • A. Clock and calendar calculations
  • B. Check digits
  • C. Hash-table bucket assignment
  • D. Checksums and error detection
  • E. Eliminating the need for cryptographic keys
View answer
Answers: A, B, C, and D. The slides connect remainders with repeating cycles, identifiers, hashing, and data-transmission checks.
7

Which statements about cryptography are supported by the slides? Select all that apply.

  • A. A key controls the transformation between plaintext and ciphertext.
  • B. Public-key cryptography can use different keys for encryption and decryption.
  • C. For the affine rule E(x)=5x+8 mod 26, decryption requires an inverse of 5 modulo 26.
  • D. Homomorphic encryption allows some computation on encrypted data.
  • E. Toy Caesar ciphers provide sufficient security for modern sensitive systems.
View answer
Answers: A, B, C, and D. The slides explicitly warn that classical toy ciphers are educational and not sufficient for modern security.
8

Which components belong in a standard mathematical-induction proof? Select all that apply.

  • A. A base case
  • B. An inductive hypothesis
  • C. An inductive step proving P(k+1)
  • D. A final conclusion stating the range for which the claim holds
  • E. Assuming P(k+1) without deriving it
View answer
Answers: A, B, C, and D. The inductive step must derive the next case from the hypothesis; it cannot simply assume the next case.
9

Which statements describe recursive definitions or algorithms correctly? Select all that apply.

  • A. They include one or more base cases.
  • B. They build or solve larger cases using smaller cases.
  • C. Memoization stores results of solved subproblems.
  • D. Naive Fibonacci recursion may recompute the same subproblem many times.
  • E. Every recursive call must use exactly the same input as the previous call.
View answer
Answers: A, B, C, and D. A recursive call normally uses a smaller or simpler input so that the process moves toward a base case.
10

Which real-world or computing applications of recursion are listed in the slides? Select all that apply.

  • A. Traversing folders and subfolders
  • B. Generating fractals and repeated graphics
  • C. Parsing expressions containing smaller expressions
  • D. Exploring game moves and countermoves in AI search trees
  • E. Requiring every dataset to be sorted before it can be processed
View answer
Answers: A, B, C, and D. These are direct examples from the Recursion II slides.
